## Project Scope

This project predicts whether a telecom customer is likely to churn (leave the service) using Machine Learning techniques. Customer demographic information, service subscriptions, billing details, and contract information are analyzed to identify churn patterns and improve customer retention strategies.

## Output

The model predicts customer churn using a Random Forest Classifier and evaluates performance using Accuracy Score, Classification Report, and Confusion Matrix. Visualizations are included to display customer churn distribution and feature importance.
